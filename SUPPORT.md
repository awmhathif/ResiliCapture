# Support

Use GitHub Issues for reproducible bugs and feature requests.

For a recording failure, include:

- ResiliCapture version
- Windows version
- recording mode (Normal/Timelapse)
- capture source and output resolution
- encoder/quality preset
- approximate recording duration
- whether the final output was created
- whether a recovery session remains

The in-app **Diagnostics** tool can create a sanitized ZIP. Review it before uploading. Never upload a private recording merely to demonstrate a bug.

Security vulnerabilities should follow `SECURITY.md` rather than a public bug issue.
