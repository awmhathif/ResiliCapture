# Privacy

ResiliCapture is designed as a local-first screen recorder.

- Recording frames are processed locally on the user's computer.
- ResiliCapture does not require an account.
- The current application does not upload recordings, screenshots, window contents, or usage analytics.
- Recovery segments and logs are stored locally.
- The optional diagnostic report excludes recordings and screenshots and sanitizes known user paths before creating the ZIP.

Screen recordings can contain passwords, messages, customer data, or other sensitive information. Users should review recordings before sharing them and should avoid attaching private recordings to public bug reports.

If networking, telemetry, crash-upload, or update-check functionality is added in a future release, this document should be updated before that release ships.
